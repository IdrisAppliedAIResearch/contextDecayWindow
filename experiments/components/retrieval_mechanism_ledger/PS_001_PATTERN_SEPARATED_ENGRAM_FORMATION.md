## 1. Trigger and program boundary

Rev 4 corrected the earlier semantic-graph construct error by implementing
learned recurrent autoassociation. The recurrence behaved mechanically:
`119/119` traces converged with non-increasing energy. The episode codes did not
behave as memories: `0/119` were fixed points and all traces collapsed into six
spurious attractors.

The failed surrogate was:

> Balanced coordinate marginals certified pattern separation.

Every Rev 4 coordinate was positive for exactly `60/119` episodes, yet pairwise
overlap reached `0.699`. Marginal balance did not remove pair dependencies or
Hebbian cross-talk.

PS-001 asks whether a deterministic sparse expansion with explicit competition
forms episode codes that are stored and minimally recoverable under a compatible
recurrent rule. It does not ask whether those codes improve retrieval, answer
Q11, bind elements within an event, or accept a natural-language partial cue.

The neuroscience claim is deliberately narrow. Pattern separation motivates a
transformation that reduces interference among similar inputs; sparse
autoassociation motivates recurrent storage and recovery under constrained
activity. PS-001 does not claim dentate-gyrus biophysics, CA3 anatomy, temporal
sequence learning, systems consolidation, or full hippocampal replication.

---

## 2. Registered question

> On the committed 119-episode store, can one deterministic sparse engram
> component produce unique fixed-cardinality codes that are all stable states
> of its learned recurrence and recover every source code after one
> deterministic active/inactive swap?

The ordered construct has three inseparable properties:

1. **Formation:** the encoder maps a dense episode vector to one unique sparse
   code without reading identity labels or measurement artifacts.
2. **Storage:** every formed code is a fixed point of the learned recurrent
   dynamics.
3. **Minimal completion:** a one-swap degraded state returns exactly to its
   source code rather than a different or spurious state.

Uniqueness, sparsity, distance, fixed-point count, or recovery count alone
cannot certify the full property.

## 4. Registered component

All equations below are implementation requirements. After the design anchor is
committed, changes require a standalone prospective amendment or reviewed
revision before affected implementation.

### 4.1 Dense input

For normalized episode vector `x_i in R^1024`, compute the committed population
center:

```text
mu = mean_i(x_i)
y_i = x_i - mu
```

`mu` is fit on the full registered episode population without labels. Input row
order must not change it beyond exact registered floating-point behavior. The
final design must specify summation order and dtype; a different BLAS reduction
is not accepted as the same encoder unless bytes reproduce.

### 4.2 Fixed sparse expansion

Construct `R in {-1, +1}^{D_CODE x 1024}` from literal seed
`0448cb7290b285bf85aa856004bd6ccbe8124aa8e3f83eaaa0225519dd626362`
using a repository-owned counter-mode SHA-256 generator. Do not use NumPy or
Python RNG version-dependent streams.

```text
activation_i = (R @ y_i) / sqrt(1024)
```

Select exactly `K_ACTIVE` unit indices by descending activation and then
ascending unit index. The sparse code is:

```text
z_i[j] = 1 if j is selected, otherwise 0
sum_j z_i[j] = K_ACTIVE
```

Content hashes, source turns, episode IDs, paths, timestamps, text, query data,
and outcome labels are forbidden encoder inputs. They may identify output rows
after encoding but cannot affect a code bit or tie.

### 4.3 Centered recurrent learning

Let `a = K_ACTIVE / D_CODE` and let `Eta` contain rows `eta_i = z_i - a`.
The conceptual learned matrix is:

```text
W = sum_i outer(eta_i, eta_i) / (D_CODE * a * (1 - a))
diag(W) = 0
```

The production implementation must not materialize the full dense matrix. At
`D_CODE=8192`, float64 materialization alone costs 512 MiB per cell. Instead it
applies the algebraically exact low-rank operator:

```text
denom = D_CODE * a * (1 - a)
diagonal = column_sum(Eta * Eta) / denom
W_times(v) = Eta.T @ (Eta @ v) / denom - diagonal * v
```

`Eta`, `diagonal`, and the formula version are the learned operator state and
must reproduce by bytes. A materialized slow reference is required on small
fixtures, and registered real-state field vectors must match a chunked
independent implementation within a tolerance fixed before exploration.

The conceptual `W` must be finite, symmetric, deterministic, and exactly
zero-diagonal. No episode similarity graph, nearest-neighbor edge, query,
content identity, or measurement label enters the operator.

### 4.4 Fixed-cardinality recall

Recall starts from binary state `s` with exactly `K_ACTIVE` active units. At
each synchronous sweep:

```text
field = W_times(s - a)
s_next = indicator(top K_ACTIVE field values; ties by unit index)
```

Stop at an exact fixed point, an exact repeated state, or after `D_CODE` sweeps.
A repeat that is not a fixed point is a cycle, not convergence. The runtime
guard is not success.

Synchronous fixed-cardinality competition does not inherit Rev 4's Hopfield
energy monotonicity guarantee. The final design must not retain an energy gate
whose theorem no longer applies. It records the registered quadratic score
descriptively and gates exact state behavior directly.

### 4.5 Deterministic degraded cues

For each content SHA-256, derive two independent coordinate permutations with
domain-separated counter streams:

```text
active_order   = permute(indices where z_i == 1, seed = SHA256("active" || content_sha))
inactive_order = permute(indices where z_i == 0, seed = SHA256("inactive" || content_sha))
```

For swap count `r`, deactivate the first `r` active indices and activate the
first `r` inactive indices. Every cue retains exactly `K_ACTIVE` active units.

Registered levels:

- Binding minimal level: `r = 1`.
- Descriptive basin levels: `r = floor(0.10 * K_ACTIVE)`,
  `floor(0.30 * K_ACTIVE)`, and `floor(0.50 * K_ACTIVE)`.

If a percentage rounds to zero, that configuration is structurally invalid for
the descriptive grid and fails exploration rather than silently substituting
one swap.

## 5. Preflight Part 1 - exploration before final design

Part 1 runs only after this exploration protocol and its standalone
authorization are committed. It remains label-blind and produces no Q11 or
retrieval outcome.

### 5.1 Required candidate grid

Characterize these nine exact cells:

```text
(D_CODE, K_ACTIVE)
(2048, 20)   (2048, 41)   (2048, 102)
(4096, 41)   (4096, 82)   (4096, 205)
(8192, 82)   (8192, 164)  (8192, 410)
```

The columns correspond to target activity levels 1%, 2%, and 5%, rounded by
exact integer half-up arithmetic. The integer counts above are authoritative;
runtime code does not recompute them from floating-point percentages. Missing,
duplicate, or silently skipped cells fail Part 1.

This is mechanism exploration, not confirmatory evidence. No claim may report
the selected cell's same-store result as an unbiased estimate.

### 5.2 Behavioral identity

For every cell, execute the component and state one falsifiable sentence:

> At `(D_CODE, K_ACTIVE)`, the encoder formed `U/119` unique exact-sparsity
> codes; the recurrence stored `F/119` as fixed points and recovered `C/119`
> deterministic one-swap cues exactly, converging to `B` unique terminal
> states with `S` spurious and `Y` cyclic traces.

### 5.3 Name-to-behavior checks

Every named term is tested on committed real traces:

- `sparse`: every state has exactly `K_ACTIVE` active units at every sweep.
- `expansion`: output dimension equals the registered `D_CODE` and exceeds
  input dimension where claimed.
- `pattern separation`: report the complete input-similarity/code-overlap joint
  distribution, especially the closest input pairs; do not substitute unique
  code count.
- `engram`: used only for the formed internal code, not as a biological claim.
- `learned`: independently reconstruct `W` from the formed codes.
- `recurrent`: prove one sweep's output becomes the next sweep's input.
- `fixed point`: an additional exact sweep changes zero units.
- `pattern completion`: exact source-code recovery from the registered degraded
  cue, not nearest-code decoding.
- `competition`: every sweep selects exactly the registered active count.
- `basin`: report all tested perturbation outcomes; do not infer untested basin
  volume.

### 5.4 Required distributions

Commit the full, identity-keyed distributions rather than summaries alone:

- Per-unit activation counts and per-code active counts.
- Pairwise input cosine, code overlap, and code Hamming distance for all 7,021
  episode pairs.
- Projection activation margins at the `K_ACTIVE` boundary.
- Fixed-point changes for all 119 uncorrupted codes.
- One-swap recovery, terminal identity, sweeps, cycles, and spurious states for
  all 119 codes.
- The same trace fields at 10%, 30%, and 50% swaps if the ordered gates reach
  those levels.
- Terminal basin cardinalities and collision membership.
- Conceptual-weight sign, magnitude, density, and row-norm distributions,
  computed in deterministic chunks without retaining the full matrix, plus
  complete field-margin distributions.
- Every cross-cell pattern, weight, trace, and terminal-sequence SHA-256.
- Per-cell peak resident memory and wall time, with execution stopped before a
  registered resource ceiling is crossed.

### 5.5 Degenerate and absorbing states

After uncorrupted storage and one-swap gates pass for a cell, run:

- Four content-hash-seeded exact-sparsity random states.
- The `K_ACTIVE` lowest-index units active.
- The `K_ACTIVE` highest-index units active.
- The union-biased state formed from the most common active units.
- Every stored code and every registered degraded cue to intended length.

Record fixed points, cycles, runtime-guard exits, spurious terminals, dominant
basins, and repeated-state hashes. Attractors are intended absorbing states;
the audit distinguishes stored from spurious absorbing states rather than
requiring none.

### 5.6 Rev 4 reproduction and non-identity

Before opening PS-001 output, a separate worktree checked out at Rev 4 must
reproduce:

- `119/119` converged traces.
- `0/119` stored fixed points.
- Six terminal states with basin sizes `5, 13, 15, 20, 29, 37`.
- Result SHA-256
  `1942950078E0A7EB30619F66356E0373208372415B401B61A49DAE6FE8CDAA78`.

Then prove PS-001 is not a relabeling of Rev 4: sparse state space, fixed
cardinality, projection, centered weights, and competition must all appear in
executed traces. If the candidate reduces to median bipolar encoding or
unconstrained sign recall, stop as `NO_NEW_MECHANISM`.

### 5.7 Exploration selection rule

Cells are considered in this order:

1. Exclude any cell that fails input integrity, exact sparsity, determinism,
   unique codes, reference equivalence, or cycle handling.
2. Exclude any cell with fewer than `119/119` stored fixed points.
3. Exclude any cell with fewer than `119/119` exact one-swap recoveries.
4. Among remaining cells, maximize exact 10% swap recovery count.
5. Break ties by smaller `D_CODE`, then smaller `K_ACTIVE`.

If no cell remains, disposition is `NO_VIABLE_SPARSE_CODE` and the study stops.
The grid cannot be expanded after output. If one cell remains, commit a final
design revision naming it before any later evidence or interpretation work.

## 6. Ordered construct gates

These gates apply to each exploration cell in order. A failure stops later cue
levels for that cell but does not skip the required record.

### G1 - Input and encoder integrity

- Exactly 119 finite normalized input vectors reproduce by content identity and
  byte digest.
- Projection bytes reproduce from the committed seed and repository-owned
  generator.
- Exactly 119 codes are produced; every code is binary and has exactly
  `K_ACTIVE` active units.
- All 119 code hashes are unique.
- Encoder leakage and forbidden-input sentinels pass.

Failure: `INVALID_ENCODER`.

### G2 - Recurrent identity

- `Eta`, the zero-diagonal correction, and operator version independently
  reproduce by bytes; a materialized small-fixture matrix is finite, symmetric,
  and exactly zero-diagonal.
- An independent slow oracle reproduces every state transition and terminal
  result on committed synthetic fixtures. A chunked independent operator
  reproduces registered real-state fields within the pre-registered tolerance.
- Every sweep preserves exact active count.
- Cycles and runtime-guard exits cannot be reported as convergence.

Failure: `INVALID_RECURRENCE`.

### G3 - Stored-code gate

Starting from each uncorrupted code, all `119/119` states must be exact fixed
points after one additional sweep. Comparison uses full code bytes and content
identity.

Failure: `SPARSE_CODES_NOT_STORED`.

### G4 - Minimal completion gate

Starting from each deterministic one-swap cue, all `119/119` traces must
converge to the exact source code. Wrong stored codes, spurious fixed points,
cycles, and runtime exits all fail.

Failure: `NO_EXACT_ONE_SWAP_COMPLETION`.

### G5 - Basin characterization

Run the registered 10%, 30%, and 50% swap levels and degenerate cues. This gate
requires complete deterministic reporting, not a favorable recovery count.

Failure: `INCOMPLETE_BASIN_CHARACTERIZATION`.

### Exploration disposition

| First binding result | Disposition |
|---|---|
| Historical reproduction or non-identity fails | `INVALID_EXPLORATION` |
| Candidate reduces to Rev 4 | `NO_NEW_MECHANISM` |
| No cell passes G1-G2 | `NO_VALID_IMPLEMENTATION` |
| At least one valid cell exists but none passes G3 | `NO_STORED_SPARSE_CODE` |
| At least one cell passes G3 but none passes G4 | `NO_VIABLE_SPARSE_CODE` |
| One or more cells pass G4 and G5 reporting completes | `SPARSE_ENGRAM_CANDIDATE_CHARACTERIZED` |

Every result is capped at `CHARACTERIZED`. No Q11, targeted retrieval, live
run, promotion, or adoption follows automatically.

## 9. Leakage and controls

### 9.1 Mechanism boundary

Mechanism, formation, learning, recurrence, and gating code may read only:

- Normalized episode vectors.
- Registered population center and projection bytes.
- Registered component parameters.
- Stable output identities supplied after code formation.

They may not read episode text, source turns, content hashes as features,
queries, fact keys, rubrics, domain labels, retrieval ranks, packing artifacts,
or prior outcome labels.

Enforce with:

- Recursive source grep.
- AST/import-graph traversal.
- Runtime path guards.
- A planted forbidden-import module that must fail before encoding.
- A planted content-hash-as-feature violation that must fail.
- A sentinel proving row reorder changes only output order, not identity-bound
  code bytes after remapping.

### 9.2 Historical control

Rev 4 is reproduced from checked-out prior code in a separate worktree. Do not
implement the control by disabling sparse encoding in current-study code.

Before execution record:

- Worktree path and clean status.
- Checked-out commit and source hashes.
- Python, NumPy, BLAS/thread environment, command, PID, and platform.
- Database and vector digests.
- Exact expected Rev 4 result digest.

Unexpected diffs, import escape, wrong commit, wrong source hash, dirty
worktree, or current-study module visibility fail before control execution.

references, and explicit `NOT_REACHED` reasons. Counts without identity lists
and digests do not reproduce the mechanism.

## 15. Stop rules

Stop immediately if:

- The final design is not committed before implementation.
- Authorization is absent or does not bind the exact design hash.
- Required input, projection, fixture, or historical artifact is absent or
  changes digest.
- Rev 4 fails exact separate-worktree reproduction.
- Leakage, import isolation, stable identity, reference equivalence, or
  determinism fails.
- A threshold is unreachable on the committed synthetic fixture.
- The registered peak-memory or wall-time ceiling is exceeded.
- The nine-cell grid is incomplete or a parameter is changed after output.
- No cell passes the registered selection rule.
- Any code reads Q11, fact, rubric, domain, retrieval, packing, or live-answer
  artifacts.
- Interpretation attempts to promote same-store exploratory selection into a
  confirmatory result.

Stopping is a valid result. It must be committed and reported rather than
repaired silently.

## 16. Permitted interpretation

If no cell passes G3:

> Under the registered sparse expansion and centered recurrent rule, none of
> the characterized configurations stored all 119 codes. Sparse activity alone
> did not solve attractor formation.

If a cell passes G3 but none passes G4:

> The component formed stored sparse codes but did not demonstrate a minimal
> recovery basin. Fixed points were not sufficient pattern completion.

If at least one cell passes G4:

> The component demonstrated exact sparse-code storage and registered
> code-space completion on this 119-episode store. This does not demonstrate
> natural-language cue completion, retrieval improvement, answer correctness,
> or biological replication.

Prohibited interpretations:

- "The hippocampus was replicated."
- "Q11 is solved" or "retrieval improved."
- "Sparse codes generalize" without a new population.
- "Natural partial cues work" from bit-swap recovery.
- "The best grid cell is confirmatory."
- "No spurious attractors exist" beyond registered cues.
