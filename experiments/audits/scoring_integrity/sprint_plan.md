# Scoring Integrity Audit - Sprint Plan

The locked pre-registration governs on any conflict. Commit order is a deliverable.

## SIA_001 - Lock

Commit methodology, standing protocol, criteria/script-derived variants, seeds,
rater configuration, synthetic calibration set and result, and author decisions.
No preserved answer is opened for re-scoring before this commit.

## SIA_002 - Criteria Guidance

Extract Q11 and Q14 criteria verbatim and commit deterministic scoring guidance
with synthetic examples. Do not inspect preserved answers while authoring it.

## SIA_003 - Mechanical Sweep

Hash-register all in-scope artifacts, inventory expected/preserved items, classify
completeness and `NO_ANSWER`, extract fact presence, check score/rationale
consistency, and commit Layer 1 before blind scoring.

## SIA_004 - Blind Re-scoring

Build an anonymized corpus and sealed mapping. Run three independent clean-context
AI passes, commit them, compute H1-H5 triggers, then obtain the separately
authorized clean-context adjudications. H4/H5 are adjudicated before evidence
reveal.

## SIA_005 - Cascade

Unseal only after scores are committed. Join original, AI, mechanical, and
adjudicated values; compute corrected totals; recompute every affected bar and
cross-study reference.

## SIA_006 - Publication

Publish additive corrected artifacts, report every directional change, add report
correction banners, and index corrections in root `ERRATA.md`.

## SIA_007 - Prevention

Install deterministic completeness/evidence checks and tests that reject positive
scores on `NO_ANSWER`, truncation, missing rationales, and evidence conflicts.
