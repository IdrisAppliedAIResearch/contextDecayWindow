The original registration and first preflight evidence are preserved. The user's standing instructions authorize AI scoring and end-to-end completion; this repair introduces no human-review claim or new retrieval factor.

For every unique primary judge item, obtain a fourth, separate fresh-context adjudication at seed9200 using the identical blinded HH-001 question/gold/answer prompt, runtime and generation settings. It sees neither arm identity, previous votes/rationales, retrieval diagnostics nor paired results. Using the same model is a disclosed correlated-instrument limitation, not independent-model or human adjudication. Auditing all primary items covers disagreement, mechanical fact-presence conflict and random-control triggers without selecting cases by favorable outcomes. Historical H4 Q11/Q14 scripted items are absent from LoCoMo; no such item is waived or excluded.

Literal containment does not certify semantic correctness: paraphrases and contradictions containing a reference string are explicit residuals. The gold/answer text and every rationale remain committed. Commit all four raw passes before aggregating scores. The adjudication vote takes precedence for the **primary** correctness endpoint; report original three-pass majority and disagreement/adjudication-change counts as sensitivity. Malformed, capped, empty, reasoning-exposing or missing-rationale judgments still fail closed. Both prospective effect bars, populations, guardrails and bootstrap are unchanged; this is not an accuracy-based threshold repair. No prior vote or outcome informed this amendment.
