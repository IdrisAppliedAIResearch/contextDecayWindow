# Retrieval Bakeoff Memory Update

- Survey status: complete; negative result on the architectural pivot.
- T1.2's best single 32k retrieval block from the compact Study 007 L store
  surfaced 8/17. This is not a universal end-to-end answer ceiling.
- T1.3's added reinforcement hypothesis was not confirmed: K-in-N overlap
  declined over time in both Study 009 S and Study 010 S.
- Tier 2 produced several exact-provenance mechanical advancements. Its 257
  wrong-turn/role lexical collisions were never credited, so recall arithmetic
  is usable but no unqualified semantic-retrieval claim is valid.
- Tier 3's oracle routing gain was 6.09%, below the build threshold.
- Tier 4 graph methods did not clear the binding gate; Tier 4B was not run.
- Tier 5 found no recall collapse above 2x budget, while approximate retrieval
  degraded at synthetic scale and progressive search did not solve old facts.
- The first Tier 6 run scored 6.5 but is invalid for architectural inference
  because live N ordering diverged from calibration. It remains preserved.
- The corrected Tier 6 run passed offline/live equivalence and two independent
  35-turn ablations, then scored 11.0/13 and Q14 1.0 under blinded scoring.
- Same-seed 121-turn comparison: plain STM 9.0, widened STM 11.0 with 13/17
  Q11 facts, LTM 12.0. Both failed Q11; the entire one-point gap is Q4.
- Widened STM delivered all six previously formation-blind plants at their
  relevant probes and correctly used five; dual mandate was delivered but
  omitted from Q11. The six plants and Q11's 17 atoms are different sets.
- This 6/6 availability and 5/6 correct-use result is the memory track's first
  clean positive result. Raw, non-entity-gated delivery solved the hardest
  documented formation failure and supports the entity-centric differentiation
  claim, though it is not a direct HippoRAG benchmark.
- Greater volume explains part, but not all, of LTM's observed advantage.
- No 1,000-turn run is authorized. A future run could only ask whether the
  volume effect persists or inverts under rendering saturation, under a new
  pre-registration.
- Immediate gap question: why widened STM omitted Q4's four-fact identity
  bundle while LTM selected it. The bundle was planted at turn 55, 60 turns
  before Q4. It ranked 27th within N=32, but only 15 N episodes fit the payload;
  K cosine was 0.166 below 0.48. This was N-first packing exclusion.
- Best-supported verdict: LTM is a primacy mechanism; no other function has
  beaten matched raw volume. Next study should test a small, always-rendered
  persistent-entity fact set with update replacement and no inference calls.
- Enumeration remains a separate shared failure.
